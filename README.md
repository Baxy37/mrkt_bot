# MRKT Bot — Telegram аналитик для маркетплейса

Бот мониторит лоты MRKT, рассчитывает потенциальную прибыль, ликвидность и рейтинг, присылает уведомления.

## Возможности
- Сканирование новых лотов с настраиваемым интервалом
- Расчёт спреда, прибыли, ликвидности и рейтинга
- Три режима: тестовый (только логи), аналитический (уведомления), полуавтомат (подтверждение перед покупкой)
- Фильтрация по бюджету, минимальной прибыли, рейтингу, чёрному списку коллекций
- Статистика за день, неделю, месяц
- Полностью настраивается через переменные окружения и команды бота

## Установка и запуск локально
1. Клонируйте репозиторий
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте: `source venv/bin/activate` (Linux/Mac) или `venv\Scripts\activate` (Windows)
4. Установите зависимости: `pip install -r requirements.txt`
5. Скопируйте `.env.example` в `.env` и заполните своими значениями (обязательно укажите `BOT_TOKEN`)
6. Запустите: `python -m app.main`

## Деплой на Render
1. Создайте новый Web Service на Render, подключите репозиторий
2. Добавьте переменные окружения (см. `.env.example`)
3. Render автоматически использует `render.yaml` для настройки
4. Для базы данных создайте PostgreSQL (или используйте SQLite, но тогда уберите `DATABASE_URL`)

## Команды бота
- `/start` — приветствие и справка
- `/status` — статус мониторинга, текущий режим, статистика
- `/stats` — детальная статистика за период (день/неделя/месяц)
- `/settings` — просмотр и изменение настроек (режим, пороги, чёрный список)
- `/pause` — приостановить мониторинг
- `/resume` — возобновить мониторинг
- `/help` — помощь

## Примечания
- Автопокупка отключена по умолчанию, реализована только в полуавтоматическом режиме с подтверждением (кнопка "Купить" отправляет ссылку на лот, покупка не выполняется автоматически)
- Для замены источника данных (MRKT) отредактируйте адаптер в `scanner.py`
